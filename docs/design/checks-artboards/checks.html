2 · The first Check now: what will start

Checking an MCP server means starting it, and that runs code: a script in your repo, or a package fetched from npm or PyPI. So the first time, FlowForge lists exactly what will start and waits for you. You confirm once per map version; a re-scan that changes a command asks again. "Check without them" checks everything else and leaves the servers grey.
