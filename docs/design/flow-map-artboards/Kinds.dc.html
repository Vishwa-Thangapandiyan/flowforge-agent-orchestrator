Flow map: the building blocks

Every map the Planner draws is made from these blocks, and it only shows apps your code already calls. Each block carries evidence from the repo or from the test run; a block without evidence is dropped or shown as unconfirmed.

Order of control

1The Planner reads and runs

Reads the repo, runs the app in test mode, traces every outside call, then proposes the map.

2FlowForge checks

Loops, missing apps, unknown tools, blocks with no evidence. Gates are added by code, not by the Planner.

3You edit

Move, rewire, swap an app, add or hide a step. Saved on top of the Planner's map. Your code isn't touched.

4Re-check shows a diff

The Planner never overwrites. You pick what to take; the old version stays runnable.

The Planner decides what runs. The scheduler decides when. You approve anything that moves money or sends a message.
