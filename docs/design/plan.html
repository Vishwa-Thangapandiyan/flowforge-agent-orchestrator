Three rules

Storage, keys, LLMs

Storage

Grow only when needed

  • SQLite solo or self-hosted (today)
  • Postgres teams, many users
  • Redis only for live traffic between machines

No cloud needed to start.

API keys

Never on screen

  • Keys live in env vars, not workflow JSON.
  • Redact outputs before saving or streaming.
  • Dashboard shows "configured" or "missing".
  • Scan code for leaked keys with regex + entropy + AST. No LLM.

Say "catches known formats", never "catches everything".

LLMs

NVIDIA NIM is the free default

  • Same interface for OpenAI, Anthropic, Gemini, Ollama.
  • Ollama keeps sensitive data on your machine.
  • Free tier has rate limits. Check NVIDIA's terms before heavy use.
Approval gates

Risky steps wait for you

Anything that touches payments or changes code pauses until you click Approve. This is the feature that makes it an orchestrator and not only a monitor.
