Behind the curtain

Redact, edit, restore

Your hackathon trick, inside FlowForge. The AST finds the key, a vault remembers it, and the LLM only ever sees a placeholder.

Your codeconst rz = new Razorpay({ key_id: "rzp_live_aj9391…" });
LLM seesconst rz = new Razorpay({ key_id: "<REDACTED_RAZORPAY_KEY_1>" });
LLM writesconst stripe = new Stripe("<REDACTED_STRIPE_KEY_1>");
After restoreconst stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

The real value goes into .env, which stays out of git. Your code only names it.

Every placeholder comes back onceIf the LLM drops, edits or invents one, the run stops.
Scan the result for key-shaped stringsThis catches an LLM that makes up a plausible key.
Logs show placeholders onlyThe dashboard and run history never see the real value.
